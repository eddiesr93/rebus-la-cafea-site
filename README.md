Site static HTML/CSS, fără scripturi, formulare sau instrumente de analiză a utilizării. GitHub Pages publică ramura `main`, directorul rădăcină. Fișierul `.nojekyll` permite servirea directă a fișierelor.

Acest repository conține numai site-ul informativ. Actualizările se pregătesc în directorul `SupportSite` din proiectul privat și se copiază aici; codul aplicației nu se publică în acest repository.
