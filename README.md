Paginile publice de suport și confidențialitate pentru aplicația iPhone Rebus la cafea.

- [Suport](https://eddiesr93.github.io/rebus-la-cafea-site/)

Stare: paginile sunt publicate prin GitHub Pages. Proprietarul a aprobat publicarea site-ului și a acestui repository, inclusiv istoricul său, pe 5 octombrie 2026.

Site static HTML/CSS, cu capturi din aplicație în `img/` și fonturi găzduite local în `fonts/` (Bricolage Grotesque și Atkinson Hyperlegible Next, licență SIL OFL), fără scripturi, formulare, resurse externe sau instrumente de analiză a utilizării. Secțiunea temporară „Strigoi și dovleci” din `index.html` se scoate după 3 noiembrie 2026. GitHub Pages folosește ramura `main`, directorul rădăcină. Fișierul `.nojekyll` permite servirea directă a fișierelor.

Acest repository conține numai site-ul informativ. Actualizările se pregătesc în directorul `SupportSite` din proiectul privat și se copiază aici; codul aplicației nu se publică în acest repository.
